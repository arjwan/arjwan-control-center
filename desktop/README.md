# مركز الأرجوان — Windows

نسخة سطح مكتب مستقلة من لوحة مركز الأرجوان الحالية، تعمل دون إنترنت لعرض قائمة التطبيقات وأحدث تقرير محفوظ. لا تعني حالة `offline` أن الخدمات متوقفة؛ بل إن الفحص الحي غير متاح.

## التشغيل والتجميع

```bash
npm install
npm run desktop:dev
npm run desktop:dist
```

ينتج البناء مُثبّت NSIS لنظام Windows في مجلد `dist/`. يلزم تنفيذ البناء على Windows، ورفع الإصدار وتوقيعه رقمياً قبل توزيعه تجارياً.

## الربط بالخدمة الإلكترونية

عرّف متغير البيئة `ARJWAN_CONTROL_STATUS_URL` ليشير إلى العنوان الكامل `https://.../api/status` الخاص بمركز الأرجوان المنشور، ثم شغّل التطبيق. لا يُضمَّن أي رمز سري في نسخة سطح المكتب. يُحفظ آخر تقرير ناجح في مجلد بيانات التطبيق المحلي، ويُعرض في وضع عدم الاتصال.

التطبيقات المعروضة مأخوذة من `shared/apps.js`، وهو فهرس مبدئي، وليست جميع التطبيقات مثبتة محلياً تلقائياً. زر «فتح» يفتح مواقع HTTPS في المتصفح الخارجي؛ لا يسمح هذا الإصدار بتشغيل أو إدارة برامج Windows الأخرى بلا موافقة أو ربط مخصص.

## الأمان والحدود

- لا تعطِ التطبيق مفتاح Cloudflare أو GitHub أو كلمات المرور.
- المراقبة المحلية ليست بديلاً عن خادم مراقبة مستقل: حين تنقطع الشبكة، تبقى آخر قراءة فقط.
- التحكم بالتراخيص والإيقاف والتحديث وتثبيت التطبيقات يتطلب خادماً مصادقاً عليه وتفويضاً لكل وظيفة، ولا يُفعّل بمجرد إضافة واجهة Windows.
- هذه حزمة بناء أولية غير موقعة؛ يلزم اختبار مُثبّت فعلي على Windows 10/11 قبل وصفها بالجاهزة للتوزيع.
