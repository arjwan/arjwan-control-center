# لوحة تحكم الأرجوان

مركز قيادة واحد لتطبيقات أرجوان سوفت وير: التطبيقات، السيرفرات، قواعد البيانات، التراخيص، المراقبة، والتحديثات.

## الحالة الحالية

المرحلة الأولى: **قراءة فقط**. لا تُنفَّذ أي أوامر على الخدمات، ولا تُرسل أي بيانات اعتماد.

| القسم | الحالة |
|---|---|
| التطبيقات | يعمل — فحص حي لكل تطبيق |
| السيرفرات | يعمل — فحص استضافة وواجهات |
| التحديثات | يعمل — آخر commit لكل مستودع GitHub |
| قواعد البيانات | بانتظار مفتاح Cloudflare API (قراءة فقط) |
| التراخيص | بانتظار خادم تراخيص |
| المراقبة | يعمل — فحص كل ٦٠ ثانية |

## البنية

```
index.html              الواجهة (عربي RTL)
assets/app.js           العرض والتفاعل
assets/styles.css       التنسيق
shared/apps.js          قائمة التطبيقات والخدمات والمستودعات
functions/api/status.js نقطة الفحص على Cloudflare Pages Functions
tools/status-check.mjs  فحص من سطر الأوامر
tools/dev-server.mjs    خادم محلي للتطوير
```

## التشغيل محلياً

```
node tools/dev-server.mjs
```

ثم افتح `http://localhost:8788`.

فحص سريع من الطرفية:

```
node tools/status-check.mjs
```

## النشر على Cloudflare Pages

1. اربط المستودع بمشروع Pages جديد.
2. إعدادات البناء: لا أمر بناء، ومجلد الإخراج هو جذر المستودع.
3. الدوال تُكتشف تلقائياً من `functions/`.

## الخطوات التالية

- إضافة مفتاح Cloudflare API بصلاحية قراءة لعرض D1 وR2 وسجلات النشر.
- ربط خادم تراخيص لعرض الأجهزة والتفعيل.
- تنبيهات (بريد/ويب هوك) عند توقف أي خدمة.
- أفعال إدارية (نشر، نسخ احتياطي، تفعيل) خلف تأكيد صريح لكل عملية.
