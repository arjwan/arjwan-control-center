# لوحة تحكم الأرجوان

مركز قيادة واحد لتطبيقات أرجوان سوفت وير: التطبيقات، السيرفرات، قواعد البيانات، التراخيص، المراقبة، والتحديثات.

## الحالة الحالية

المراقبة متاحة، وتعمل إدارة المشاريع والتراخيص بعد تهيئة قاعدة D1 ومفتاح الإدارة.

| القسم | الحالة |
|---|---|
| التطبيقات | يعمل — فحص حي لكل تطبيق |
| السيرفرات | يعمل — فحص استضافة وواجهات |
| التحديثات | يعمل — آخر commit لكل مستودع GitHub |
| قواعد البيانات | بانتظار مفتاح Cloudflare API (قراءة فقط) |
| التراخيص | إصدار وتعليق وإلغاء بعد تهيئة قاعدة D1 |
| المراقبة | يعمل — فحص كل ٦٠ ثانية |

## البنية

```
index.html              الواجهة (عربي RTL)
assets/app.js           العرض والتفاعل
assets/styles.css       التنسيق
shared/apps.js          قائمة التطبيقات والخدمات والمستودعات
functions/api/status.js نقطة الفحص على Cloudflare Pages Functions
tools/status-check.mjs  فحص من سطر الأوامر
tools/dev-server.mjs    خادم محلي للتطوير
```

## التشغيل محلياً

```
node tools/dev-server.mjs
```

ثم افتح `http://localhost:8788`.

فحص سريع من الطرفية:

```
node tools/status-check.mjs
```

## النشر على Cloudflare Pages

1. اربط المستودع بمشروع Pages جديد.
2. إعدادات البناء: لا أمر بناء، ومجلد الإخراج هو جذر المستودع.
3. الدوال تُكتشف تلقائياً من `functions/`.

## الخطوات التالية

- إضافة مفتاح Cloudflare API بصلاحية قراءة لعرض D1 وR2 وسجلات النشر.
- تنبيهات (بريد/ويب هوك) عند توقف أي خدمة.
- أفعال إدارية (نشر، نسخ احتياطي) خلف تأكيد صريح لكل عملية.

## إدارة المشاريع والتراخيص

من تبويب التراخيص، أدخل مفتاح الإدارة لإضافة المشاريع وتسجيل الطلبات وقبولها
أو رفضها وإلغاء التراخيص الصادرة. التجريبي 30 يومًا والسنوي سنة والدائم بلا
تاريخ انتهاء. تعليق مشروع يعطّل تحقق جميع تراخيصه حتى استئنافها. يظهر مفتاح
الترخيص عند الإصدار فقط. إذا فُقد المفتاح، ألغِ الترخيص وأصدر بديلًا.

هذه الإعدادات تخص وظيفة التراخيص على Cloudflare Pages.

1. أنشئ قاعدة D1 مخصصة للوحة ونفّذ `migrations/0001_control.sql` عليها.
2. اربط القاعدة بدوال Pages باسم `CONTROL_DB`.
3. ولّد سرًّا باستخدام `openssl rand -hex 32` وأضفه كسر باسم
   `CONTROL_ADMIN_TOKEN`، ثم أعد نشر المشروع. استخدم قاعدة وسرًا مستقلين
   لإعدادات المعاينة والإنتاج.
4. استخدم رابط HTTPS للوحة. لا تحفظ مفتاح الإدارة داخل تطبيقات العملاء.

يرسل تطبيق العميل طلب POST إلى `/api/control?action=verify` بنوع
`application/json` وبحقلي `projectId` و`key`. يحتوي الرد على `valid`،
وعند نجاح التحقق يعود نوع الباقة وتاريخ الانتهاء. على التطبيق اعتماد
قرار التحقق ضمن سياسة تشغيله. تعليق التراخيص لا يطفئ الاستضافة، والتحقق
المركزي يتطلب اتصالًا. تطبيقات الدسكتوب أوف لاين تحتاج دمج آلية تحقق محلية
قبل أن تعتمد على هذه اللوحة.
