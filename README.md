# مركز تحكم الأرجوان

التصميم الفاتح الأرجواني المعتمد، مع الاستفادة من فحص الخدمات في النسخة السابقة. شنو منو مستثنى.

المراقبة: /api/status يفحص روابط ثابتة فقط، مع مهلة وتصنيف HTTP. استجابة 200 تثبت وصول الرابط فقط. 401/403 تعني الوصول محمي. لا يعني عدم تسجيل رابط أن التطبيق غير منشور.

التراخيص والطلبات وسجل العمليات: سجلات محلية في المتصفح حتى اكتمال ربط الخادم. لا تصدر مفاتيح أو تنفذ إيقافاً فعلياً. قواعد البيانات غير مربوطة.

Cloudflare Pages: لا أمر بناء، مجلد الإخراج جذر المشروع. يجب حماية اللوحة و/api/* بالمصادقة قبل استخدامها خارج معاينة خاصة. لا توضع أسرار أو بيانات عملاء في المستودع.

الاختبارات: npm test.
